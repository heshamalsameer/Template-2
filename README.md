# leon — Playful Creative Agency Template

A colourful, one-page website for a small creative agency, with a hand-made sticker look and a sense of humour.

**Sections:** hero · features · services (with the "I need food" flip card) · process · portfolio + lightbox · about · contact · footer

Built with plain HTML, CSS and vanilla JavaScript. No build step needed: open `index.html` in a browser.
